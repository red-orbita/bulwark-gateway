Integrations

Outbound case-management connectors. Push an investigation case to an external SOC platform (TheHive, DFIR-IRIS, OpenCTI, MISP, or a TAXII 2.1 collection as a STIX bundle). Pushes are fail-open — a remote error is retried and audited but never blocks the local case. Re-pushing the same case updates the existing remote record instead of creating a duplicate. Secrets are write-only and masked in every response.
