Session Decomposition Tracker

Catches multi-turn decomposition attacks — a dangerous request split into individually-benign chunks across requests. The proxy accumulates weighted "threat signals" per session (tenant+agent) across a 5-minute and a 30-minute window; crossing a threshold escalates to WARN/BLOCK. Threshold changes below write to Redis and the proxy honors them within ~5s without a restart. Session keys are irreversible SHA-256 digests. All mutations are audit-logged.
