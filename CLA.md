## How to Sign

We accept CLA acceptance in the following ways (any one is sufficient):

1. **Per-pull-request statement (individuals, simplest).** Add the following line
   to the description of your first pull request:

   ```
   I have read and agree to the Bulwark Gateway CLA (Individual, Section A).
   Signed-off-by: Your Name <your.email@example.com>
   ```

2. **Signed record in the PR (corporate).** An authorized representative of the
   entity opens (or comments on) the contributor's first pull request with:

   ```
   On behalf of <Legal Entity Name>, I have read and agree to the Bulwark Gateway
   CLA (Corporate, Section B).
   Authorized by: <Name>, <Title>
   Entity: <Legal Entity Name>
   Designated Employees / accounts: <github-username-1>, <github-username-2>, ...
   ```

3. **Email.** Send the equivalent statement to the Owner at the contact address
   published in the repository. Include your name, GitHub username, and (for
   corporate) the entity name and authorized signer.

By signing in any of the ways above, You agree to the applicable Section of this
Agreement for your present and future Contributions to the Project.
